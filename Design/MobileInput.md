# Mobile input

## Our choice for the form of input

### Drag and drop/Clicking directly

We chose this form since its really the only one that makes sense.

**Pros**
- Implementing is simple and flexible for different objects with different functionalities

**Cons**
- Some objects might be difficult to know that you have to touch them.

## Partly implemented

### Moving objects with a connected mouse

Used mostly for testing purposes.

**Pros**
- Works the same as our actual choice.
- Can be easier to use for physically limited people.

**Cons**
- Doesn't really make sense to implement as a main method of input for a game made to be played with a touch screen.

## Other choices and why they weren't chosen

### Virtual controller

**Reason**
- Since the player has to choose the object he wants to interact with we would have to implement Drag and drop anyway.
- Multiplayer element is cut almost completely

### Tilting the device

**Reason**
- Could be fun if the player played on a smaller device but the game is made for the YETI.
